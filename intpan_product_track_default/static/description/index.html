Default Storable Products

New products Track Inventory by default — everywhere.

In Odoo 18 every new product is created with Track Inventory turned off. Forget to enable it once, and the product never shows up in your stock, valuation or reordering. This module makes every new product Storable by default, no matter which app creates it.

The problem

Setting the default with Set Defaults does not work: that value is contextual and Odoo ignores it when the product is created from Sales or Purchase. So your team keeps creating products with no inventory tracking — and nobody notices until the stock report is wrong.

The solution

This module overrides the default at model level. Every new product is born with Track Inventory enabled — from Sales, Purchase, Inventory, imports or the API. Need a service or a non-tracked good? Just uncheck the box. That simple.

Works everywhere

Sales, Purchase, Inventory, imports and API. If it creates a product, it tracks inventory.

Zero configuration

Install it and you are done. No settings, no menus, nothing to maintain.

Always reversible

Any product can be turned into a service or non-tracked good with a single click.

Privacy

This module does not collect, store or send any user data to external services.
